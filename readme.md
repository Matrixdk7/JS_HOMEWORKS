### Homework #2-3

A questionnaire that collects basic information about the user, and then displays the summary in a single alert.

Using a `prompt`, ask in sequence:
- Name
- Age
- City
- Do you like JavaScript? (user enters "yes" or "no")

After that:

- Store the value in a `primitive type variable`.
- Convert the answer about JavaScript to a `boolean value`:
  if the user entered "yes" (in any case: "yes", "Yes", "YES") → consider true otherwise → false

Form a single line for the `alert`, for example:
"Hello, Ivan! You are 25 years old, you are from Kyiv. Attitude towards JavaScript: likes." or "... Attitude towards JavaScript: dislikes."
