### Homework #11-2

Your function should repeat the basic functionality of the `flat` method, but with some improvements.

- The function accepts only 1 argument - an array,
- The function returns only a one-dimensional array
- If the user passes more than one argument, throw an error to the console

- If a multidimensional array is passed to the function, then it must return a new one-dimensional array.
- If a one-dimensional array is passed to the function, then it must return a new array that is a complete copy of the one passed.

P.S. The use of the `flat` method is prohibited
